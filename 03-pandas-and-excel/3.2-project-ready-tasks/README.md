# 3.2 Project-Ready Tasks — Pandas and Excel

This directory contains practical, real-world data processing tasks covering Pandas fundamentals, cleaning pipelines, joins, transformations, OpenPyXL Excel styling, and performance vectorization.

## Progression Index

| Directory | Topic | Key Focus & Scenario |
|---|---|---|
| `01-dataframes/` | DataFrames & Series | Ingestion, boolean filtering, column slicing, and `.describe()` metrics |
| `02-data-cleaning/` | Data Cleaning | Remediation of nulls, duplicates, bad date formats, and string whitespace |
| `03-transformations/` | Transformations | Relational joins, multi-metric `groupby`, calculated columns, and pivots |
| `04-excel-workbooks/` | Excel Automation | Generating styled multi-sheet Excel reports with OpenPyXL formatting |
| `05-validation/` | Data Validation | Building an automated audit engine that segregates valid and quarantined rows |
| `06-performance/` | Performance & Vectorization | Vectorized operations vs `iterrows()`, downcasting, and memory profiling |

## How to Run

```bash
python <topic_folder>/<script_name>.py
```
