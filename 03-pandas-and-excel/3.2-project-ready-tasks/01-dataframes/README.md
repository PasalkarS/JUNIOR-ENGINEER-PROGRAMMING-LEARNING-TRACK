# 01 — DataFrames Inspection & Filtering

## Objective
Inspect, slice, filter, and summarize e-commerce order data using Pandas Series and DataFrames.

## Key Concepts
- `.shape`, `.dtypes`, and `.describe()` for instant dataset profiling.
- Boolean mask filtering: `df[df['amount'] > 500]`.
- Subset selection with column lists.

## How to Run
```bash
python dataframe_inspection.py
```
