# Module 03: Pandas and Excel

Welcome to **Module 03: Pandas and Excel** of the Junior Engineer Programming Track.

## Learning Structure

- `3.1-learned/`: 6 comprehensive `.docx` topic guides covering DataFrames/Series, data cleaning, transformations, Excel automation with OpenPyXL, validation pipelines, and performance vectorization.
- `3.2-project-ready-tasks/`: 6 task folders with scripts on inspection, cleaning pipelines, relational merges, styled Excel sheets, audit engines, and vectorization benchmarks.
- `3.3-independent-project-excel-to-report-pipeline/`: Complete automated ETL pipeline with schema validation, analytics aggregations, multi-tab styled Excel reports, and automated tests.
