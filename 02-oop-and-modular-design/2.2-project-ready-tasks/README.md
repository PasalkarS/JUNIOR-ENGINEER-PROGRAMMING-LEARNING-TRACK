# 2.2 Project-Ready Tasks — OOP and Modular Design

This directory contains progressive implementation tasks designed to build strong object-oriented and software architecture skills in Python.

## Progression Index

| Directory | Topic | Scenario & Implementation |
|---|---|---|
| `01-classes-and-objects/` | Classes & Objects | Domain modeling of `Customer`, `Product`, `OrderItem`, and `Invoice` |
| `02-encapsulation/` | Encapsulation | Guarding invariants with `@property` setters against illegal values |
| `03-inheritance-and-composition/` | Inheritance & Composition | Notification delivery channels and payment gateway comparisons |
| `04-interfaces-and-abstraction/` | Interfaces & Abstraction | Abstract `UserRepository` with InMemory and JSON implementations |
| `05-modular-architecture/` | Modular Architecture | Converting a 1-file monolith into models, repository, and service layers |
| `06-design-principles/` | SOLID & Clean Design | Refactoring bad SRP/DIP violations into maintainable decoupled classes |

## How to Run

```bash
python <topic_folder>/<script_name>.py
```
