# Junior Engineer Programming Learning Track

This repo is my personal study log as I work through Delta IoT Solutions' 2-week Junior Engineer Learning Track. It isn't tied to any client or customer project—it's dedicated time for me to sharpen my core programming skills, build solid engineering habits, and get hands-on with the tools and workflows we use day-to-day.

## How I'm working through this

For every module, I follow a four-step progression to make sure concepts stick:

1. **Learn**: Read through docs, understand key ideas, and write exploratory scripts in `learned/` to see how things work under the hood.
2. **Practice**: Work through targeted exercises and real-world patterns to turn theory into muscle memory.
3. **Build**: Assemble working utilities or mini-features under `project_ready/` that meet practical quality standards.
4. **Independent Challenge**: Tackle an unassisted problem or edge case in `independent/` from scratch without relying on tutorials or step-by-step guides.
