# User Guide

## Running the Application

From the project root:

```bash
python src/tracker.py
```

## Available Operations

1. **Add Expense**: Prompts for category, amount, description, and date.
2. **List Expenses**: Shows a tabular view of all recorded expenses.
3. **Add Asset**: Records capital items (laptops, vehicles, inventory) with estimated values.
4. **List Assets**: Displays active asset portfolio.
5. **Search Records**: Filters records by keyword across category or description.
6. **Financial Summary**: Computes total asset value, total expenditures, and net balance.
