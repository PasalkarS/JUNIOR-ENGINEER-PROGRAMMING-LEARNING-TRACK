# 03 — Collections Practice

This directory contains programs demonstrating lists, dictionaries, sets, comprehensions, and data aggregation.

## Included Scripts

1. `inventory_tracker.py`: Dictionary lookups, stock updates, and low-stock filter comprehensions.
2. `employee_directory.py`: Sets for unique values, list comprehensions, and metric calculations.
3. `transaction_aggregator.py`: Categorizing, summing, and summarizing structured transactions.

## How to Run

```bash
python inventory_tracker.py
python employee_directory.py
python transaction_aggregator.py
```
