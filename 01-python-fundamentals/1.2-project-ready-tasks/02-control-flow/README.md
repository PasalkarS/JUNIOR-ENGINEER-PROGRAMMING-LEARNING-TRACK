# 02 — Control Flow Practice

This directory contains programs demonstrating conditional branching, loops, loop controls, and menu systems.

## Included Scripts

1. `number_analyzer.py`: Multi-branch `if / elif / else` counting sign and parity.
2. `pattern_generator.py`: Nested `for` loops and range step manipulation.
3. `search_and_filter.py`: Using `continue` to filter and `break` to short-circuit search.
4. `menu_loop.py`: A `while True` loop pattern for interactive CLI menus.

## How to Run

```bash
python number_analyzer.py
python pattern_generator.py
python search_and_filter.py
python menu_loop.py
```
