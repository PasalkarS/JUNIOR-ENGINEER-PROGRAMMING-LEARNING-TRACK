# 05 — Strings & Files Practice

This directory contains programs demonstrating text parsing, structured file formats (CSV), and log parsing.

## Included Scripts

1. `log_parser.py`: Parses server log formats, tallies status levels, and filters error rows.
2. `csv_report_generator.py`: Ingests CSV data with `csv.DictReader` and produces regional sales summaries.

## How to Run

```bash
python log_parser.py
python csv_report_generator.py
```
