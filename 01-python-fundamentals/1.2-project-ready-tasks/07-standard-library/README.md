# 07 — Standard Library Practice

This directory contains programs demonstrating Python's standard library modules: `datetime`, `json`, `collections.Counter`, and `statistics`.

## Included Scripts

1. `date_calculator.py`: Date arithmetic with `timedelta` and weekday filtering.
2. `json_transformer.py`: Deserialization, configuration updates, and formatted serialization.
3. `frequency_counter.py`: Word frequency counting with `Counter` and statistical summaries.

## How to Run

```bash
python date_calculator.py
python json_transformer.py
python frequency_counter.py
```
