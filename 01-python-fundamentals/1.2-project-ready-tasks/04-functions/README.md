# 04 — Functions & Modular Utilities

This directory contains functional utilities demonstrating pure functions, default arguments, type annotations, and function dictionaries.

## Included Scripts

1. `math_utils.py`: Reusable statistics functions (`calculate_mean`, `calculate_median`, `clamp`).
2. `string_formatter_utils.py`: String masking, slug generation, and clean truncation.
3. `refactored_calculator.py`: Refactored arithmetic engine using function mapping dictionaries.

## How to Run

```bash
python math_utils.py
python string_formatter_utils.py
python refactored_calculator.py
```
