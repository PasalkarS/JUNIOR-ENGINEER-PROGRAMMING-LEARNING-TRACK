# 06 — Exceptions & Defensive Programming

This directory contains utilities for validating data types, enforcing business rules, raising custom exceptions, and safely managing file I/O operations.

## Included Scripts

1. `validation_guards.py`: Custom exception hierarchy (`ValidationError`) and input sanitization.
2. `safe_file_loader.py`: Graceful error recovery using `try-except-else-finally`.

## How to Run

```bash
python validation_guards.py
python safe_file_loader.py
```
