# 1.2 Project-Ready Tasks — Python Fundamentals

This directory contains practical, beginner-friendly programming tasks designed to build muscle memory and solid understanding of core Python concepts.

## Progression Path

| Directory | Topic | Key Focus |
|---|---|---|
| `01-syntax-and-execution/` | Syntax & Types | 20 small standalone scripts practicing variables, types, and arithmetic |
| `02-control-flow/` | Control Flow | Conditionals, while loops, patterns, and interactive CLI menu loops |
| `03-collections/` | Collections | List/dict inventory, employee lookup directory, transaction aggregator |
| `04-functions/` | Functions | Reusable pure functions, modular calculator, and string math utilities |
| `05-strings-and-files/` | Strings & Files | Server log parser and CSV sales report generator with `with open()` |
| `06-exceptions/` | Exceptions | Input validation guards, custom exceptions, and defensive loading |
| `07-standard-library/` | Standard Library | Date calculator, JSON config transformer, and word counter tools |

## How to Run

Navigate to any topic folder and run each script with Python:

```bash
python <script_name>.py
```
