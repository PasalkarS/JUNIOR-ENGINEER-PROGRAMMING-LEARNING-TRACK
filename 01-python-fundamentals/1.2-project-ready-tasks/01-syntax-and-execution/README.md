# 01 — Syntax and Execution Practice Programs

This directory contains **20 small, standalone Python programs** covering syntax, variables, data types, arithmetic, type conversion, and execution flow.

## Programs Index

1. `01_hello_world.py`: Basic stdout output.
2. `02_variables.py`: Variable declaration across basic types.
3. `03_arithmetic.py`: Arithmetic operators (+, -, *, /, //, %, **).
4. `04_user_input.py`: Reading CLI input and casting to integer.
5. `05_temperature_convert.py`: Converting Celsius to Fahrenheit.
6. `06_string_concat.py`: Modern f-strings vs string concatenation.
7. `07_type_casting.py`: Explicit type conversion.
8. `08_boolean_logic.py`: Boolean expressions with `and`, `or`, `not`.
9. `09_area_rectangle.py`: Computing area and perimeter.
10. `10_simple_interest.py`: Financial math with interest calculation.
11. `11_bmi_calculator.py`: Mathematical exponents in formulas.
12. `12_swap_variables.py`: Pythonic variable swapping.
13. `13_quotient_remainder.py`: Divmod operations.
14. `14_circle_calculations.py`: Math library constants (`math.pi`).
15. `15_tax_calculator.py`: Currency rounding with `round()`.
16. `16_minutes_to_hours.py`: Converting minutes to hours/minutes.
17. `17_string_repetition.py`: String repetition and alignment.
18. `18_cube_number.py`: Power calculations.
19. `19_fstring_formatting.py`: Table column alignment with f-strings.
20. `20_entry_point_demo.py`: `if __name__ == '__main__':` pattern.

## How to Run

```bash
python 01_hello_world.py
python 15_tax_calculator.py
```
